# هدهد — همراه کاریابی

فرانت‌اند فارسی و راست‌چین با Next.js 14 که به API بک‌اند FastAPI متصل شده است.

## اجرا به‌صورت محلی

1. Node.js 18 یا بالاتر نصب باشد.
2. از بک‌اند، PostgreSQL و API را طبق README بک‌اند اجرا کنید (پیش‌فرض `http://localhost:8000`).
3. در پوشهٔ فرانت‌اند:
   ```bash
   cp .env.example .env.local
   npm install
   npm run dev
   ```
4. `http://localhost:3000` را باز کنید. در صفحهٔ اول ثبت‌نام یا ورود کنید.

اگر API روی آدرس دیگری اجرا می‌شود، مقدار `NEXT_PUBLIC_API_URL` را در `.env.local` تغییر دهید و Next.js را دوباره اجرا کنید.

## اتصال‌های انجام‌شده

- ثبت‌نام و ورود واقعی با ذخیرهٔ توکن JWT و هدر Authorization
- محافظت صفحات داشبورد با بررسی `/api/auth/me`
- مصاحبهٔ مرحله‌ای با ایجنت از طریق `/api/agent/conversations` و `/messages`
- تولید و نمایش آخرین رزومهٔ ذخیره‌شده
- جست‌وجوی آگهی‌ها از `/api/jobs` و تحلیل تناسب با `/api/jobs/{id}/match`

## نکات مهم

- برای اجرای قابلیت‌های هوش مصنوعی، بک‌اند به کلید معتبر ارائه‌دهندهٔ LLM نیاز دارد؛ کلید را فقط در `.env` بک‌اند بگذارید، نه در فرانت‌اند.
- فهرست آگهی‌ها از API بک‌اند می‌آید. در نسخهٔ فعلی باید آگهی‌ها در دیتابیس وارد شده باشند؛ اتصال به منبع زندهٔ آگهی هنوز جداگانه لازم است.
- قبل از انتشار عمومی، CORS بک‌اند را به دامنهٔ واقعی فرانت‌اند محدود کنید و HTTPS را فعال کنید.
